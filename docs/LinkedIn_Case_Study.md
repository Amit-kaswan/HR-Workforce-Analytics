# HR Workforce Analytics Dashboard

## Problem Statement

HR teams often struggle to monitor workforce metrics because employee information is spread across multiple reports. This makes it difficult to identify workforce trends and make timely, data-driven decisions.

---

## Objective

The objective of this project was to build an interactive HR Workforce Analytics Dashboard that provides a centralized view of workforce metrics and supports evidence-based decision-making.

---

## Tools Used

- Microsoft Excel
- SQL
- Power BI

---

## Project Workflow

1. Data Cleaning using Excel
2. Data Analysis using SQL
3. Dashboard Development using Power BI
4. Business Insights
5. Business Recommendations

---

## Dashboard Features

- KPI Cards
- Department-wise Employee Distribution
- Attrition Analysis
- Gender Distribution
- Salary Analysis
- City-wise Distribution
- Interactive Filters

---

## Key Business Insights

- Finance department recorded the highest attrition rate.
- Workforce distribution across departments was visualized.
- Salary and employee demographics were analyzed.
- HR managers can quickly monitor workforce trends from a single dashboard.

---

## Business Recommendations

The current dataset identifies **what** is happening but does not explain **why** it is happening.

Before making recommendations, additional HR data such as employee feedback, exit interviews, overtime, workload, promotion history, and expected salary versus actual salary should be collected to identify the root causes of attrition.
