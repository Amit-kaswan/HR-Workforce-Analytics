# 1. Business Background

Human Resources (HR) teams manage large amounts of employee data every day. However, converting this data into meaningful insights is often difficult without a centralized reporting system.

This project was developed to help HR managers monitor workforce metrics and make data-driven decisions using an interactive Power BI dashboard.

---

# 2. Business Problem

The HR department needs a single dashboard to monitor:

- Workforce Size
- Employee Attrition
- Salary Distribution
- Employee Demographics
- Department-wise Analysis
- Location-wise Distribution

Without proper analytics, identifying workforce trends and retention issues becomes difficult.

---

# 3. Project Goal

To build an interactive HR Workforce Analytics Dashboard that enables HR teams to monitor key workforce metrics and support data-driven decision-making.

---

# 4. Stakeholders

- HR Manager
- HR Business Partner
- Department Managers
- Senior Management

---

# 5. Project Scope

## Included

- Workforce Analysis
- Attrition Analysis
- Salary Analysis
- Gender Distribution
- Department Analysis
- City-wise Analysis
- KPI Dashboard
- Executive Summary

## Excluded

- Predictive Analytics
- Machine Learning
- Payroll Processing
- Real-Time Data Refresh

---

# 6. Success Criteria

The dashboard should enable HR teams to:

- Monitor workforce metrics from one place.
- Identify departments with high attrition.
- Understand workforce demographics.
- Support workforce planning.
- Make evidence-based decisions.

# 8. Expected Business Impact

The dashboard helps HR managers quickly identify workforce trends, monitor attrition, and make informed decisions that support employee retention and workforce planning.
