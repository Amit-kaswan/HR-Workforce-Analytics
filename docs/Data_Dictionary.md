## Dataset Overview

This dataset contains employee information used for workforce analysis, attrition analysis, salary analysis, and employee demographics.

---

## Data Dictionary

| Column Name | Data Type | Description |
|-------------|-----------|-------------|
| Employee_ID | Integer | Unique employee identifier |
| Gender | Text | Employee gender |
| Department | Text | Employee department |
| City | Text | Employee work location |
| Salary | Decimal | Monthly salary |
| Experience | Decimal | Years of experience |
| Age | Integer | Employee age |
| Attrition | Text | Indicates whether an employee has left the company |
